# A Calm Start

This is a short, permissive example book. Its only purpose is to let the
**rebook** tool run out of the box on a fresh clone — the content here is
deliberately trivial and MIT licensed, so it is safe to commit.

## Why a book stays calm

A well-structured EPUB reads like a quiet evening: each chapter appears on
its own, the prose is set, and the computer does the turning.

> Sleep on a tricky problem and the type checker becomes a night-light.

## Emphasis and inline code

Use `cargo build --release` to make a lean binary, then *preview* it or
**push** it. Order matters: stop the viewer before you rebuild on Windows,
or the `.exe` stays locked and your change silently never lands.
