# The KDP Check

Before you hand a file to Amazon, run the local previewer: it prints every
rule that Kindle Direct Publishing cares about and marks each one green or red.

```bash
cargo run --release -- view --port 8090
```

Open <http://127.0.0.1:8090/>. For one book you land on its index; for several
you get a shelf. The **KDP-сумісність** panel (or `/check`) lists the 
mimetype-first rule, required entries, OPF metadata, spine count, the nav TOC,
and forbidden constructs. When everything is green, the EPUB is ready to drop
into KDP as-is — no AZW3 step needed.
