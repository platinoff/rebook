# Markdown, Rendered

rebook turns your markdown into strict EPUB 3.2 XHTML. It supports the basics
you expect plus a few niceties for a print-like feel.

## What is supported

- `##` and `###` headings
- blank-line paragraphs
- `>` blockquotes
- ``` fenced ``` code blocks
- inline `code`, _emphasis_, and **strong**

## A fancy quote

> Code is a poem you run. The compiler is the first reader who never tires.

## Keep it escapable

Raw `&`, `<`, and `>` must be escaped in XHTML. rebook does that for you, and
its KDP check (the `/check` route of the viewer) flags any stray unescaped
ampersand or forbidden tag like `<script>` or `<iframe>`.
